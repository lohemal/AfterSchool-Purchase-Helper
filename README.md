# 방과후 품의 도우미

초등학교 방과후 **교재비·재료비 품의**를 자동으로 작성해 주는 Windows 프로그램입니다.

거래처마다 형식이 제각각인 견적서를 읽어 품목을 뽑고, 정산자료와 맞춰 본 뒤
**에듀파인에 올릴 품의 파일(XLSX)** 을 만듭니다.

> 지금까지는 견적서를 하나씩 열어 품목과 금액을 손으로 옮겨 적어야 했습니다.
> 이 프로그램은 그 옮겨 적는 일을 대신합니다. **맞는지 확인하는 일은 사람이 합니다.**

---

## 읽을 수 있는 견적서

| 형식 | 어떻게 읽나 |
|---|---|
| `XLSX` · `XLS` · `XLSM` | 표를 그대로 읽습니다 |
| `HWP` · `HWPX` | 한글 문서의 표를 읽습니다 (HWP 는 한글 프로그램 필요) |
| `PDF` | 글자가 든 PDF 는 글자와 좌표로, 스캔본은 사진처럼 읽습니다 |
| `JPG` · `JPEG` · `PNG` | Windows 내장 글자 인식으로 읽습니다 |

PDF 는 **확장자가 아니라 내용을 보고** 글자 PDF 인지 스캔본인지 스스로 가릅니다.

---

## 일하는 순서

```
견적서 등록        파일 이름으로 부서·거래처를 자동으로 찾습니다
   ↓
자동 추출          품목·규격·수량·단가·금액을 뽑습니다
   ↓
사람이 확인        잘못 읽힌 줄은 노랗게 표시됩니다. 고치거나 지웁니다
   ↓
정산자료 불러오기   부서별 재원 금액을 읽습니다
   ↓
재원 배분          거래처가 여럿이면 사람이 나눕니다 (프로그램이 나누지 않습니다)
   ↓
검증               세로·가로 두 방향으로 금액을 맞춰 봅니다
   ↓
품의자료 생성       재원마다 에듀파인 업로드용 XLSX 를 만듭니다
```

작업은 저장되므로 프로그램을 껐다 켜도 하던 자리에서 이어서 할 수 있습니다.

작업을 만들 때 **이름을 직접 지을 수 있고**, 나중에 이름만 바꿀 수도 있습니다.
이름을 바꿔도 등록한 견적서와 정산·배분 자료는 그대로입니다.
더 필요 없는 작업은 지울 수 있습니다. 지우면 그 작업의 자료가 함께 사라지지만
**원본 견적서 파일과 만들어 둔 Excel 은 지우지 않습니다.**

---

## 이 프로그램이 지키는 것

- **자료가 이 컴퓨터 밖으로 나가지 않습니다.** 견적서도 정산자료도 어디에도 보내지 않습니다.
- **외부 AI 서비스를 쓰지 않습니다.** 글자 인식은 Windows 에 들어 있는 기능을 씁니다.
  인터넷 없이도 모든 기능이 됩니다.
- **원본 견적서를 고치지 않습니다.** 열어서 읽기만 합니다.
- **글자 인식 결과를 혼자 확정하지 않습니다.** 사진에서 읽은 견적서는 언제나 `확인 필요`
  상태로 시작하고, 사람이 확인해야 다음으로 넘어갑니다.
- **금액이 맞지 않아도 프로그램이 고치지 않습니다.** 예를 들어 `수량 3 × 단가 10,000` 인데
  금액이 `80,000` 으로 적혀 있으면 30,000 으로 바꾸지 않고 **금액 검증 실패**로 알립니다.
- **만든 파일을 덮어쓰지 않습니다.** 같은 이름이 있으면 `… (2).xlsx` 로 비켜 만듭니다.
- **로그에 개인정보를 남기지 않습니다.** 품명·상호·금액·파일 경로를 적지 않습니다.

---

## 쓰기 전에 필요한 것

| | |
|---|---|
| 운영체제 | Windows 10 · 11 (64비트) |
| HWP 견적서를 읽으려면 | 한글(HWP) 프로그램이 깔려 있어야 합니다. 없으면 HWP 만 못 읽고 나머지는 그대로 됩니다 |
| 사진 견적서를 읽으려면 | Windows 의 **한국어 광학 문자 인식**이 필요합니다. 보통 이미 켜져 있습니다. 없으면 프로그램이 켜는 방법을 알려 줍니다 |

---

## 설치 방법

1. [Releases](https://github.com/lohemal/AfterSchool-Purchase-Helper/releases) 에서
   `afterschool-purchase-helper_0.1.1_x64-setup.exe` 를 내려받습니다.
2. 내려받은 파일을 두 번 눌러 실행합니다. **관리자 권한이 필요 없습니다.**

### "Windows의 PC 보호" 창이 뜬다면

이 프로그램은 유료 코드 서명 인증서로 서명되어 있지 않습니다.
그래서 Windows 가 처음 보는 프로그램이라며 파란 창을 띄웁니다.

> **추가 정보** 를 누른 뒤 **실행** 을 누르면 설치됩니다.

개인이 만든 서명 없는 프로그램은 모두 이렇게 나옵니다.
**프로그램이 Windows 보안 설정을 끄거나 검사에서 빼는 일은 하지 않습니다.**

## 자료는 어디에 있나요

```
%APPDATA%\kr.school.afterschool-purchase-helper\purchase-helper.db
```

프로그램이 설치된 폴더가 **아닙니다.** 그래서 새 버전으로 올려도, 프로그램을 지웠다 다시 깔아도
작업이 그대로 남습니다. 프로그램을 지울 때 이 자료는 지워지지 않습니다.
정말 지우고 싶으면 위 폴더를 직접 지우면 됩니다.

만든 품의 파일은 사용자가 고른 폴더에 저장되며, 그 위치를 기억해 다음에도 같은 곳을 씁니다.

---

## 업데이트

새 버전이 나오면 프로그램을 켤 때 알려 줍니다.
**[지금 업데이트]** 를 누르면 받아서 설치하고 다시 켜집니다.

- 확인은 프로그램이 켜진 뒤에 조용히 합니다. 시작을 막지 않습니다.
- 새 버전이 없으면 아무것도 보여 주지 않습니다.
- 인터넷이 없거나 확인에 실패해도 프로그램은 그대로 씁니다.
- **사람이 누르기 전에는 설치하지 않습니다.**

직접 확인하고 싶으면 **부서 설정** 화면 맨 아래 **프로그램 정보** 에서
지금 버전을 보고 **[업데이트 확인]** 을 누르면 됩니다.
최신인지, 새 버전이 있는지, 확인하지 못했는지를 그 자리에서 알려 줍니다.

---

## 지금의 제한

- Windows 전용입니다.
- HWP 견적서는 한글 프로그램이 깔린 PC 에서만 읽습니다.
- 글자 PDF 는 화면 안에서 원본을 보여 주지 못합니다. **[원본 파일 열기]** 로 확인합니다.
  (PDF 를 그리는 큰 라이브러리를 넣지 않기로 했습니다.)
- 복합기로 스캔한 PDF 는 실제 업무 자료로 아직 시험해 보지 못했습니다.
  기울어진 스캔본을 바로잡는 기능은 없습니다.
- 사진 한 장을 읽는 데 몇 초가 걸립니다. 읽는 동안 진행 상태를 보여 줍니다.
- 견적서를 읽지 못해도 **품목을 직접 입력**할 수 있으므로 작업이 막히지는 않습니다.

## 개발

```bash
npm install
npm run app          # 개발 실행
npm run build        # 타입 검사 + 화면 빌드
npm run check:model  # 계산·표시 규칙 시험 (브라우저 없이)
npm run check:version # 버전 선언이 다섯 곳 모두 같은지
npm run app:build    # 설치 파일 만들기

cd src-tauri
cargo test --lib                          # 서버 시험
cargo test --lib -- --ignored             # 한글 COM · 글자 인식이 필요한 시험
```

실제 업무 샘플(`test/fixtures-local/`)에는 거래처 개인정보와 학교 회계 자료가 들어 있어
**저장소에 넣지 않습니다.** 그 샘플이 필요한 시험은 없으면 스스로 건너뛰고,
나머지 시험은 내려받은 그대로 전부 돌아갑니다.

설계와 결정 과정은 `docs/` 에 있습니다.
