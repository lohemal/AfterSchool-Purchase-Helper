# 방과후 품의 도우미 v0.1.0

방과후 **교재비·재료비 품의**를 자동으로 작성해 주는 첫 공개 버전입니다.

거래처마다 형식이 다른 견적서를 읽어 품목을 뽑고, 정산자료와 맞춰 본 뒤
에듀파인에 올릴 품의 파일을 만듭니다. 견적서를 하나씩 열어 손으로 옮겨 적던 일을 대신합니다.

---

## 할 수 있는 일

**여러 형식의 견적서를 읽습니다**
엑셀(XLSX·XLS·XLSM), 한글(HWP·HWPX), PDF, 사진(JPG·JPEG·PNG).
PDF 는 확장자가 아니라 내용을 보고 글자 PDF 인지 스캔본인지 스스로 가릅니다.

**견적서에서 품목을 자동으로 뽑습니다**
품명·규격·수량·단가·금액을 읽습니다. 할인 줄, 금액이 0원인 사은품 줄, 합계 줄을 구분해
「N종」과 총액에 알맞게 반영합니다.

**사진과 스캔본은 글자 인식으로 읽습니다**
Windows 에 들어 있는 글자 인식 기능을 씁니다. 외부 서비스로 자료를 보내지 않습니다.

**읽은 결과를 사람이 확인합니다**
다시 봐야 할 줄은 노랗게 표시되고 까닭이 한 줄 붙습니다. 그 자리에서 고치거나 지울 수 있습니다.
사진·스캔본에서 읽은 견적서의 원본은 화면 안에서 바로 볼 수 있습니다.

**정산자료와 연결합니다**
부서별 재원 금액을 읽어 옵니다. 정산자료에 여러 이름으로 나뉜 강좌는 한 부서로 합산합니다.

**거래처별로 재원을 나눕니다**
한 부서에 거래처가 여럿이면 사람이 나눕니다. **프로그램이 비율로 자동 배분하지 않습니다.**

**금액을 두 방향으로 검증합니다**
재원별 합(세로)과 거래처별 합(가로)을 함께 맞춰 봅니다. 어긋나면 빨갛게 막고,
사유를 적어야 다음으로 넘어갑니다.

**에듀파인 품의자료를 만듭니다**
재원마다 XLSX 를 만들고, 만든 파일을 **다시 읽어** 규격대로인지 확인한 뒤 내놓습니다.

**작업을 저장하고 이어서 합니다**
프로그램을 껐다 켜도 하던 자리에서 계속할 수 있습니다.

---

## 이 프로그램이 지키는 것

- 자료가 이 컴퓨터 밖으로 나가지 않습니다. 인터넷 없이도 모든 기능이 됩니다.
- 외부 AI 서비스를 쓰지 않습니다.
- 원본 견적서를 고치지 않습니다. 열어서 읽기만 합니다.
- 글자 인식 결과를 혼자 확정하지 않습니다. 사람이 확인해야 넘어갑니다.
- 금액이 맞지 않아도 프로그램이 고치지 않습니다.
  `수량 3 × 단가 10,000` 인데 금액이 `80,000` 이면 30,000 으로 바꾸지 않고 **금액 검증 실패**로 알립니다.
- 만든 파일을 덮어쓰지 않습니다. 같은 이름이 있으면 `… (2).xlsx` 로 비켜 만듭니다.
- 로그에 품명·상호·금액·파일 경로를 남기지 않습니다.

## 설치

아래 `afterschool-purchase-helper_0.1.0_x64-setup.exe` 를 내려받아 실행하세요.
**관리자 권한이 필요 없습니다.**

> Windows 가 **"PC를 보호했습니다"** 창을 띄우면 **추가 정보 → 실행** 을 누르세요.
> 코드 서명 인증서가 없는 개인 프로그램은 모두 이렇게 나옵니다.

### 쓰기 전에

- Windows 10 · 11 (64비트)
- **HWP 견적서**를 읽으려면 한글 프로그램이 깔려 있어야 합니다.
  없어도 나머지 형식은 그대로 됩니다.
- **사진 견적서**를 읽으려면 Windows 의 한국어 광학 문자 인식이 필요합니다.
  보통 이미 켜져 있고, 없으면 프로그램이 켜는 방법을 알려 줍니다.

---

## 자료는 그대로 남습니다

자료는 프로그램과 따로 `%APPDATA%\kr.school.afterschool-purchase-helper` 에 있습니다.
업데이트해도, 프로그램을 지웠다 다시 깔아도 그대로입니다.
프로그램을 지워도 이 자료는 지워지지 않습니다.

---

## 지금의 제한

- Windows 전용입니다.
- 글자 PDF 는 화면 안에서 원본을 보여 주지 못합니다. **[원본 파일 열기]** 로 확인합니다.
- 복합기로 스캔한 PDF 는 실제 업무 자료로 아직 시험해 보지 못했습니다.
  기울어진 스캔본을 바로잡는 기능은 없습니다.
- 사진 한 장을 읽는 데 몇 초가 걸립니다. 읽는 동안 진행 상태를 보여 줍니다.
- 글자 인식이 모든 글자를 맞히지는 못합니다. **확인 화면에서 고치는 것을 전제로** 만들었습니다.
- 견적서를 읽지 못해도 품목을 직접 입력할 수 있어 작업이 막히지는 않습니다.
